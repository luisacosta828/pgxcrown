    ⚡

    Zero-Copy Memory Slices

    PgText and PgVector[T] operate directly over PostgreSQL engine varlena and contiguous array buffers without intermediate heap allocation, strlen calls, or garbage collector overhead.

    0 Allocations | Direct Varlena Slicing Performance
    🛡️

    Fail-Safe PG_TRY Shield

    All exported UDFs are enclosed in compiled PG_TRY / PG_CATCH safety boundaries. Unhandled integer overflows, defects, and panics cleanly abort the transaction without killing PostgreSQL backend workers.

    0 Backend Worker Crashes | SQLSTATE Reliability
    🚀

    Sub-15ms Incremental Builds

    pgxtool computes deterministic SHA-256 source manifests to skip redundant compilations. Incremental rebuild times drop from 2.65 seconds down to 0.012 seconds with isolated per-project .pgx_build/nimcache.

    < 15ms Cache Hit | Isolated Nimcache Productivity

    Developer Onboarding

    Get Started in 60 Seconds

    1

    Install Framework via Nimble

    nimble install -y pgxcrown
    2

    Scaffold & Build Extension

    pgxtool init && pgxtool create-project analytics
pgxtool build-extension analytics
    3

    Install & Enable in PostgreSQL

    sudo ./analytics/src/install.sh
psql -U postgres -c "CREATE EXTENSION analytics;"
