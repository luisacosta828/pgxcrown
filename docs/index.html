Production Capabilities

What Pgxcrown Can Do Right Now

Every feature built directly into the framework to supercharge your PostgreSQL extension development.

⚡

Native C Codegen (Zero VM)

Compiles directly to native C dynamic shared libraries (.so on Linux, .dll on Windows). Zero virtual machine or interpreter overhead for maximum raw CPU speed.

🪄

Auto-Generated SQL & Control Bindings

Automatically inspects your Nim functions and datatypes to produce clean CREATE FUNCTION SQL scripts and .control manifests at build time.

⚓

PostgreSQL Engine Hook Interceptors

First-class support to intercept PostgreSQL kernel event streams including emit_log (log filtering & audit logging) and post_parse_analyze (query analysis & rewriting).

🪶

Ultra-Tiny ~500KB Shared Libraries

Produces lightweight binary footprints (~500 KB - 2 MB), avoiding heavy language stdlib bloat and facilitating fast container image distribution.

🛡️

Static Compile-Time IO Safety Guard

Extension functions are statically analyzed during compilation to guarantee they operate strictly in-memory, disallowing unauthorized OS file or network socket operations by design.

🛠️

`pgxtool` Automated CLI Suite

Complete CLI tool to initialize environments, scaffold UDFs, types, and hooks, build release binaries, auto-install into Postgres directories, and run Docker tests.

Quickstart

Get Started in Seconds

Install Pgxcrown via Nimble and start creating your first native extension.

1. Install Pgxcrown via Nimble:
nimble install pgxcrown
2. Initialize environment & scaffold project:
pgxtool init && pgxtool create-project my_extension
3. Build, auto-generate SQL bindings, & install:
pgxtool build-extension my_extension && pgxtool install my_extension
