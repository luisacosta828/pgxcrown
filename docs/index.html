Comprehensive Capabilities

Every Feature of Pgxcrown

Designed from the ground up to bring modern language ergonomics and enterprise security to PostgreSQL C extensions.

🛡️
v0.14.0 Spotlight

Non-STRICT Null-Datum Defense

Automatically intercepts isArgNull(n) on non-strict functions, safely substituting zero-values ("", 0, @[]) to prevent null pointer dereferences and SEGV crashes.

🔢
v0.13.2 Spotlight

Dynamic & Composite Array Mapping

Bidirectional zero-copy mapping between Nim sequences (seq[T]) and PostgreSQL dynamic arrays (int4[], text[], bool[], record[]), including custom object & tuple record arrays.

💡
v0.13.0 Spotlight

Default & Option[T] NULL Defense

Maps Nim default parameters to SQL DEFAULT DDL, extracts SQL NULLs into Option[T] via isArgNull, and returns SQL NULL cleanly on none(T).

🛡️
v0.12.0 Spotlight

Automatic Panic Shield

Intercepts integer overflows, array out-of-bounds, nil dereferences, and defects at compile time, converting panics to safe ereport(ERROR) transaction aborts.

⚡

Zero-VM Native C Codegen

Compiles directly into dynamic C shared libraries (.so / .dll). Zero virtual machine or interpreter overhead for maximum raw CPU execution performance.

🪶

~500KB Shared Libraries

Produces ultra-compact binary footprints (~500 KB - 2 MB), avoiding language runtime bloat and accelerating cloud container image distribution.

🪄

Auto-Generated SQL Bindings

Automatically inspects your Nim functions and datatypes to produce clean CREATE FUNCTION SQL scripts and .control manifests at build time.

⚓

PostgreSQL Kernel Engine Hooks

First-class support to intercept PostgreSQL kernel event streams including emit_log (log filtering & audit logging) and post_parse_analyze (query analysis).

🔢

Bidirectional Primitive Conversion

Seamless conversion between native Nim types (int32, int64, float, string, cstring, bool) and PostgreSQL engine Datum.

🏷️

PostgreSQL Enum Mapping

Automatically converts PostgreSQL ENUM OIDs into strongly-typed Nim enums and emits matching CREATE TYPE ... AS ENUM definitions.

📦

Composite Record & Tuple Reader

Inspect and extract PostgreSQL HeapTupleHeader fields directly into Nim tuple and object types with automatic ref counting.

🛠️

`pgxtool` Automated CLI Suite

Complete CLI tool to initialize workspace environments, scaffold UDFs, types, and hooks, build release binaries, auto-install into Postgres, and run Docker tests.

🚫

Compile-Time IO Safety Guard

Statically analyzes compiled functions to guarantee they operate in-memory, disallowing unauthorized OS file or network socket operations by design.

Developer Onboarding

Get Started in 60 Seconds

1

Install Framework via Nimble

nimble install pgxcrown
2

Scaffold & Build Extension

pgxtool init && pgxtool create-project my_ext
pgxtool build-extension my_ext
3

Install & Enable in PostgreSQL

sudo ./my_ext/src/install.sh
psql -U postgres -c "CREATE EXTENSION my_ext;"
